# SB Jain AWS Student Community

The official website and portal for the AWS Student Builder Group at SB Jain Institute of Technology, Nagpur.

## Features
- **AWS Community Day Theme**: Dark cinematic aesthetic with official AWS orange (#FF9900) and cyan accents.
- **Ambient Aura**: Fixed full-page animated aura blobs and drifting grid mesh matching awscommunityday.dev.
- **Live Countdown**: Real-time interactive countdown timer for upcoming flagship community events.
- **Event Architecture**: Keynotes & mentors showcase, full-day agenda timeline, venue details, and participation badge customizer.
- **Pure Web Stack**: Lightweight vanilla HTML5, CSS3, and JavaScript — zero heavy framework dependencies.

## Project Structure
- `index.html` — Main landing page and all event sections.
- `style.css` — Custom styles, keyframe animations, and responsive breakpoints.
- `script.js` — Dynamic countdown, custom cursor, particles, badge preview, and FAQ accordion.
- `images/` — Official transparent AWS vector logos (SVG / PNG) and branding assets.

## Local Preview
Simply open `index.html` in any modern browser or run:
```bash
python -m http.server 8080
```
Visit [http://localhost:8080](http://localhost:8080).
